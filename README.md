### Sobre

Atuo com qualidade de software desde 2021: testes funcionais, exploratórios, regressivos, de integração, de API REST e homologação (UAT), em ambientes ERP e sistemas web. Venho evoluindo para automação de testes, usando o Claude Code para criar, executar e analisar testes automatizados.

- 🧪 QA em ERP **TOTVS Protheus e RM**: requisitos, regras de negócio, critérios de aceite e gestão de defeitos
- 🔌 Testes de **API REST** (endpoints, métodos HTTP, status codes, payloads JSON/XML) e validação de integrações entre sistemas
- 🗄️ **SQL/MySQL** para investigação de dados e checagem de consistência e integridade
- 🤖 Automação web e **IA aplicada a QA** (geração de cenários, scripts e análise de resultados)
- 👥 Experiência prévia em liderança de equipes de teste e de desenvolvimento
- 🎓 Eng. de Computação (Anhanguera) · Pós-graduação em Engenharia de Software com ênfase em Qualidade e Teste (jan–jun/2026)
